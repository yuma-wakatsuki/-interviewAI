# 社内配布計画

## 配布物

1. Chrome 拡張機能（`dist/`）
2. Windows ローカルアプリ（FastAPI、sherpa-onnx、承認済み日本語モデル）

音声と文字起こしはローカル PC 内で処理し、外部 API とクラウド保存は使用しない。

## 段階展開

1. 開発者PCで10分・30分・60分試験
2. 面接官5名へ先行配布し、診断ログのみ回収
3. CPU、メモリ、遅延、認識品質を確認
4. Chrome 組織ポリシーまたは社内手順で30名へ展開

## 面接官向けの起動手順（配布版）

1. `InterviewAI-Local.exe` を起動する。
2. Chrome で Google Meet を開く。
3. Meet タブで InterviewAI 拡張機能アイコンをクリックする。
4. 最初の一度だけ、専用タブでマイクを許可する。
5. 面接終了時に Side Panel の停止を押し、必要なら TXT を保存する。

起動アプリが動いていない場合、拡張機能は接続エラーを表示し、音声を外部へ送信しない。

## 運用前提

- 面接開始前に録音・文字起こしの同意を取得する。
- TXT と診断 WAV は各端末の利用者が管理する。
- モデルは Apache-2.0 を確認済みの ReazonSpeech Zipformer を使う。
